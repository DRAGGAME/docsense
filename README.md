# DocSense - Telegram-бот для анализа документов

Бот принимает документ и возвращает структурированный анализ текста вместе с вопросами для самопроверки. Пользователь загружает файл, задаёт глубину разбора и сложность вопросов - и получает готовый результат прямо в чате, без ручного чтения и конспектирования.

---

## Назначение

- **Студентам** - разобраться в лекции, учебнике или параграфе и проверить понимание материала вопросами разного уровня сложности.
- **Преподавателям и методистам** - получить черновик конспекта или набор контрольных вопросов по материалу.
- **Специалистам, работающим с большим объёмом текстов** - быстро получить структурированную выжимку из отчёта, презентации или документа вместо чтения целиком.

## Как это работает для пользователя

1. Пользователь запускает бота командой `/start`.
2. Отправляет файл - PDF, Word или PowerPoint.
3. Настраивает через инлайн-кнопки:
   - уровень вдумчивости разбора (1–3);
   - уровень сложности контрольных вопросов (1–3).
4. Нажимает «Запустить» и получает готовый анализ.

## Логика анализа

Бот определяет тип текста и подбирает под него соответствующую схему разбора.

| Тип текста | Структура анализа |
|---|---|
| Научный / учебный (математика, физика, химия) | Цель материала → объяснение ключевых понятий и формул → закрепление с контрольными вопросами |
| Естественно-научный / гуманитарный (география, история, философия) | Повторение и постановка проблемы → детальный разбор тем → вопросы на закрепление |
| Художественный текст (романы, рассказы, пьесы) | Контекст и жанр → сюжет и композиция → персонажи → проблематика → художественные приёмы → критическая оценка |

Для каждого типа доступны три уровня глубины разбора - от базового ознакомления до развёрнутого аналитического разбора - и три уровня сложности вопросов - от прямого пересказа фактов до вопросов, требующих самостоятельного осмысления материала.

## Поддерживаемые форматы файлов

| Формат | Расширения |
|---|---|
| Документы | .docx, .doc, .odt |
| PDF | .pdf |
| Презентации | .pptx, .ppt, .odp |

Бот работает только с файлами, содержащими текстовый слой; сканы без распознавания текста не поддерживаются.

## О текущей реализации

Текущая версия бота построена на бесплатных провайдерах языковых моделей, что позволяет использовать продукт без затрат на платный доступ к ИИ. Это удобное решение для старта и проверки продукта, но у бесплатных провайдеров есть естественные ограничения: возможны задержки ответа и колебания качества генерации по сравнению с платными моделями.

Логика бота изначально спроектирована так, чтобы её было легко адаптировать под конкретную задачу заказчика. Бот может быть переработан под любую тематику и направление - юриспруденцию, медицину, бухгалтерию, техническую документацию, HR и любую другую область - с собственной логикой анализа, стилем ответов и набором функций. При необходимости также выполняется переход на более стабильный платный или локальный провайдер модели для повышения скорости и качества ответов.
