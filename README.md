# Бот для сокращения документов

## Проект для сокращения документов через бесплатных провайдеров LLM моделей. Изначально был написан с целью сдачи проекта. Возможно переписка под коммерческую модель и улучшеную версию в целом

## Используемые фреймворки и технологии

### - aiogram 3. Сам телеграм

### - aiosqlite. Для хранения пользователей

### - spire-pdf. Обработка pdf

### - spire-doc. Обработка документов

### - spire-presentation. Обработка презентацией

### - asyncio

### - g4f. Бесплатные провайдеры моделей

### - logging. Логгированние

### - python-dotenv

### - pyexcel-ods3. Excel таблицы
